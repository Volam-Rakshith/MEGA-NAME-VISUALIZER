## 🛠️ How It Works

```
┌─────────────────────────────────────────────────┐
│              THEME GENERATION ENGINE             │
├─────────────────────────────────────────────────┤
│                                                  │
│   20 Categories  ×  100+ Effects  ×  40 Palettes │
│              ×  55+ Fonts  ×  Name Mixer         │
│                     ⬇                            │
│           3,000+ Unique Combinations             │
│                                                  │
├─────────────────────────────────────────────────┤
│              RUNTIME ARCHITECTURE                │
├─────────────────────────────────────────────────┤
│  🖼️  Canvas API   →  Real-time animated effects  │
│  👁️  IntersectionObserver → Lazy card animation  │
│  🎥  MediaRecorder API    → WebM video capture   │
│  🧩  Custom LZW Encoder   → GIF export (inline!) │
│  📦  toDataURL()          → PNG / 4K PNG export  │
│                                                  │
└─────────────────────────────────────────────────┘
```

**Procedural Generation** — Instead of hardcoding themes, the engine combines:
- **Effect** (how it animates) × **Palette** (colors) × **Font** (typography) × **Generated Name**

This means infinite variety from a single, tiny file.
