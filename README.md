## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎨 **3,000+ Themes** | Procedurally generated from 100+ effects × 55+ fonts × 40+ color palettes |
| 🏷️ **20 Categories** | Particles, Stars, Cyberpunk, Fire, Water, Nature, Elegant, Retro, Dark, Gradient, Geometric, Sci-Fi, Minimal, Neon, Psychedelic, Weather, Holiday, Anime, Horror, Futuristic |
| ⚡ **Live Canvas Animations** | Every theme renders in real time with custom particle physics |
| 📥 **PNG Export** | Download HD `1920 × 1080` wallpapers |
| 🖼️ **4K PNG Export** | Download Ultra HD `3840 × 2160` wallpapers |
| 🎞️ **GIF Export** | Built-in **custom GIF encoder** — no external libraries needed |
| 🎬 **Video Export** | Record `.webm` clips at 5 Mbps via MediaRecorder API |
| 🔍 **Smart Search** | Search by theme name, category, effect, or font |
| ♾️ **Infinite Scroll** | Lazy loads themes as you scroll — buttery smooth |
| 🔋 **Performance Optimized** | Only visible cards animate (IntersectionObserver) |
| 🖥️ **Fullscreen Mode** | Immersive preview with `←` `→` `Esc` keyboard controls |
| 📱 **Fully Responsive** | Works on desktop, tablet, and mobile |
| 📦 **Zero Dependencies** | One `index.html` file. No npm, no build step, no CDN required |
